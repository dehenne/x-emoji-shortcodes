# Store Listing

## Short Description

Use GitHub-style `:emoji:` shortcodes while writing posts on X.

## Full Description

X Emoji Shortcodes brings GitHub-style emoji shortcodes to the X post composer.

Type shortcodes such as `:rocket:`, `:party:`, or `:fire:` while writing a post, then select a suggestion or finish a complete shortcode to insert the matching emoji. The extension also includes practical aliases such as `:flag_de:` and is based on the Gemoji dataset.

The extension runs locally in your browser, does not use analytics, does not call external APIs, and does not request broad browser permissions.

### Key Features

- Replace complete `:emoji:` shortcodes while writing posts on X.
- See autocomplete suggestions while typing partial shortcodes.
- Use keyboard controls: Arrow Up, Arrow Down, Enter, Tab, and Escape.
- Select suggestions with the mouse.
- Use more than 2,300 generated shortcode aliases from Gemoji.
- Runs locally with no analytics and no external API calls.
